## ✨ Features

- **Canvas Hero Animation** — GPU-accelerated particle/trail animation on a `<canvas>` element.
- **Bilingual (EN / ES)** — Toggle between English and Spanish without page reload.
- **Scroll-Active Navigation** — IntersectionObserver-based scroll spy highlights the current section.
- **Fully Responsive** — Works seamlessly from mobile to ultrawide.
- **Dark Theme** — Dark-first design with glassmorphism panels and gradient accents.
- **Working Contact Form** — Powered by Web3Forms; no server required.
- **SEO Optimized** — Custom meta title, description, and semantic HTML structure.
- **Smooth Scrolling** — Native `scroll-behavior: smooth` across the entire page.
- **Preloader** — Full-screen loading animation while canvas assets initialize.

## 🚀 Getting Started

### Prerequisites

- **Node.js** >= 22.12.0
- **pnpm** (recommended) or npm

### Install & Run

```bash
git clone https://github.com/equinox-1092/dev-portfolio-2026.git
cd dev-portfolio-2026
pnpm install
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

### Build for Production

```bash
pnpm build
pnpm preview
```

## 📁 Project Structure

```
portafolio/
├── public/              # Static assets (favicon, hero frames)
├── src/
│   ├── assets/          # Images and icons
│   ├── components/      # Astro components (Navbar, About, Skills, etc.)
│   ├── layouts/         # Page layout wrapper
│   ├── pages/           # Route pages (index.astro)
│   └── styles/          # Global CSS (Tailwind import + custom tokens)
├── astro.config.mjs     # Astro configuration
├── tsconfig.json        # TypeScript configuration
└── package.json
```
